Day 1 — Learn the sequence.

Start with the governing equations, identify unknowns, remove the ones you do not want, and only then insert numbers. The number of steps depends on the problem.

Exam recognition — cover the second line and recall it before opening a problem.

1 · Capillary minimum

Start ω²=gk+(γ/ρ)k³; c=ω/k

Unknowns → final One free k. Derive c²(k), set its derivative to zero, obtain kₘ, cₘ, Lₘ.

2 · Gravity swell

Start ω²=gk tanh(kh); c=ω/k; cᵍ=dω/dk

Unknowns → final k from L. Evaluate phase speed, then differentiate ω for group speed.

3 · Internal wave

Start Linear Boussinesq: ∂u/∂t=−(1/ρ₀)(∂p′/∂x); ∂w/∂t=−(1/ρ₀)(∂p′/∂z)+b; ∂b/∂t=−N²w; ∂u/∂x+∂w/∂z=0

Unknowns → final Four fields u,w,p′,b. Eliminate U,P,B to get ω²=N²k²/(k²+m²), use angle, then T.

4 · Poincaré currents

Start ∂u/∂t−fv=−g ∂η/∂x; ∂v/∂t+fu=0; ∂η/∂t+h ∂u/∂x=0

Unknowns → final Three fields (u,v,η). Apply ∂/∂t to (1), add f×(2) to cancel v; use −g∂/∂x of (3) to replace η. One PDE in u gives ω²=f²+ghk². THEN calculate Û and V̂.

5 · Rossby eastward group

Start ω=−βk/(k²+Rᵈ⁻²); cᵍ=dω/dk

Unknowns → final One k. Differentiate twice, optimize positive group speed, cᵍ,max=βRᵈ²/8.

6 · Kelvin energy

Start u=0; ∂u/∂t−fv=−g ∂η/∂x; K=½ρhv²; P=½ρgη²

Unknowns → final Eliminate v through geostrophy and Rᵈ; K/P=1.

7 · Lake seiche

Start ω²=gh(kₓ²+kᵧ²); kₓ=nπ/Lₓ; kᵧ=mπ/Lᵧ

Unknowns → final Pick lowest nonzero mode; longest basin dimension; obtain ν=ω/2π.

8 · Equatorial Rossby

Start ω≈−βk/[k²+(2n+1)Rₑq⁻²]

Unknowns → final Long limit drops k²; speed −c/(2n+1); then t=D/|speed| for n=1,2,3.

Known Q5 · Derivation

Start Three rotating shallow-water equations, initially nonlinear

Unknowns → final Linearize; eliminate ∂v/∂t and ∂²η/(∂x ∂t); get PDE in u; insert sinusoid; ω²=f²+gh₀k².

Algebra & calculus moves you will need — each one is written out line by line inside the steps

Power rule · P1

d(kⁿ)/dk = n·kⁿ⁻¹

g/k = g·k⁻¹ ⇒ d/dk = −g/k²

Product + chain rule · P2

(FG)′ = F′G + FG′

d tanh(kh)/dk = h·sech²(kh)

Quotient rule · P5

d(N/D)/dk = (N′D − ND′)/D²

d[k/(k²+a)]/dk = (a−k²)/(k²+a)²

Sinusoid derivatives · P3 P4 P7 Q5

Φ = kx − ωt: ∂Φ/∂x = k, ∂Φ/∂t = −ω

∂²/∂x² → −k²;   ∂²/∂t² → −ω²

Mixed partials · P3 P4 P7 Q5

∂²F/(∂x∂t) = ∂²F/(∂t∂x)

Lets the η terms (or p′ terms) match and cancel.

Exponential chain rule · P6

d(e−x/R)/dx = −(1/R)e−x/R

⇒ ∂η/∂x = −η/Rd

Hyperbolic identity · P2

sinh(2x) = 2 sinh x cosh x

⇒ sech²x / tanh x = 2/sinh(2x)

Dividing by a fraction · P8

A ÷ (B/C) = A·C/B

−βk ÷ [(2n+1)/R²] = −βkR²/(2n+1)
